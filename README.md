# creeperdeking.github.io

Personal site, built with React and Vite. Use Node 24.

## Scripts

### `npm start`

Starts the dev server at [http://localhost:3000](http://localhost:3000).

### `npm run build`

Builds the production site into the `build` folder.

### `npm run deploy`

Builds the site and publishes the `build` folder to the `gh-pages` branch, which hosts [creeperdeking.github.io](https://creeperdeking.github.io).
